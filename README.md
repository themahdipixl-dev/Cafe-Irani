# مرجینو (Margino)

بازی موبایل **مرج + بازسازی باغ** با تم **باغ هخامنشی (چهارباغ)**. با مرج کردن مواد (آجر لعابدار، چوب، گیاه، فلز و سفال) باغ ویران‌شده رو قدم‌به‌قدم بازسازی می‌کنی.

## وضعیت فعلی
فقط **محیط فصل اول** پیاده‌سازی شده: باغ ۳۰×۳۰ متری با دیوار، دو دروازه، حوض مرکزی، مسیرها، جوی آب و همه‌ی آیتم‌های باغ. منطق مرج، قدم‌ها و UI هنوز ساخته نشده.

## مشخصات
- **موتور:** Godot 4.7 (GDScript)، رندرر GL Compatibility
- **نما:** 2D ایزومتریک واقعی (۴۵ درجه، ارتفاع ۳۵.۲۶ درجه)، ۱۰۰ پیکسل بر متر
- **پلتفرم:** اندروید، حالت عمودی (portrait)
- **زبان:** فارسی

## اجرا
1. Godot 4.7 یا بالاتر رو نصب کن.
2. پوشه‌ی پروژه رو باز کن (بار اول ادیتور تصویرها رو import می‌کنه) و F5 بزن.
3. با کشیدن انگشت (یا موس) باغ رو جابه‌جا کن و با pinch (یا چرخ موس) زوم کن.

## ساختار
- `scenes/main.tscn` صحنه‌ی اصلی (باغ + دوربین)
- `scenes/garden.tscn` باغ فصل اول
- `scripts/config/garden_config.gd` ثابت‌ها و `world_to_screen`
- `scripts/world/garden.gd` ساخت زمین، مسیر، دیوار، آیتم‌ها و مه
- `scripts/world/garden_camera.gd` دوربین (pan و zoom)
- `data/garden_layout.json` تعریف و چیدمان آیتم‌ها
- `assets/meta/` تصویرهای آیتم‌های باغ (PNG شفاف، دو برابر اندازه‌ی نهایی)

راهنمای فنی برای توسعه در `CLAUDE.md` است.
